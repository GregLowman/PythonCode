## Key Concepts

- **`if`/`elif`/`else`**: Branching logic and compound boolean expressions (`and`, `or`, `not`).
- **`in` / `not in`**: Membership testing in strings, lists, and `range` objects.
- **`for` loops**: Iterating over strings, lists, and ranges.
- **`while` loops**: Condition-driven loops; `while`/`else` clause fires when the condition becomes false naturally.
- **`range(start, stop, step)`**: Producing integer sequences with optional step.
- **`break` / `continue`**: Early loop exit and skipping to the next iteration.
