# Scope, Time & Tkinter

Python scripts covering variable scope, the `time`/`datetime`/`pytz` modules, and Tkinter GUI programming.

## Files

| File | Description |
|---|---|
| `spam.py` | Nested function scope: inner functions closing over enclosing-scope variables |
| `scope.py` | Iterative vs recursive factorial and Fibonacci implementations |
| `functions.py` | Text-centering utility: align a string within an 80-character width |
| `more_functions.py` | Tkinter canvas demo drawing parabolas and circles |
| `files_and_directories.py` | Recursive directory listing indented by depth |
| `example.py` | Inspect public methods of `shelve.Shelf` |
| `browser.py` | Open a URL in the default web browser via `webbrowser` |
| `turtledemo.py` | Turtle graphics: spiral and geometric patterns |
| `datecalc.py` | Reaction-time game using `time.perf_counter` |
| `dateandtime.py` | Print local and UTC datetime with `datetime` |
| `challenge.py` | Timed arithmetic quiz with random operators |
| `awaretime.py` | Compare naive and timezone-aware datetimes using `pytz` |
| `tztest.py` | Print current local time for every country/timezone via `pytz` |
| `time_challenge.py` | Timezone clock: pick a country from a shelve-backed menu |
| `tkinter_demo.py` | Tkinter pack-layout intro: label, canvas, buttons |
| `Tkinter_demo_2.py` | Tkinter grid-layout demo with resizable frames |
| `screen.py` | Grid demo: file browser, radio buttons, time/date spinners |
| `tkinter_challenge_test.py` | Calculator UI prototype with title bar and button grid |
| `tkinter_challenge.py` | Calculator with resizable grid layout |
| `tkfont_finder.py` | Scrollable list of all available Tkinter font families |
| `personal_project.py` | Hangman UI scaffold: letter grid, canvas, and word slots |
| `a_thing.py` | Playable Hangman with difficulty selection and canvas drawing |
| `blackjack.py` | Tkinter Blackjack: deal, score, and compare hands |
| `import_test.py` | Module-level import test for `blackjack.py` |

## Concepts

- **Scope**: closures, `nonlocal`, nested functions
- **Time**: `time`, `datetime`, `pytz`, timezone-aware datetimes, `perf_counter`
- **Tkinter**: `pack` and `grid` layouts, `Canvas`, `Spinbox`, `Scrollbar`, `PhotoImage`, event loop
