# Big-O and Sorting Functions

Bubble sort implementations demonstrating algorithm efficiency and step-by-step visualization.

## Files

| File | Topic |
|---|---|
| `bubble_sort.py` | Standard bubble sort with pass-by-pass output and comparison counting |
| `animated_bubble_sort_1.py` | Terminal-animated bubble sort using `colorama` — highlights the compared pair at each step |

## Key Concepts
- Bubble sort algorithm: O(n²) time complexity, O(1) space
- Early exit optimization when no swaps occur in a pass
- ANSI escape codes for terminal cursor control and color output
- `colorama` for cross-platform terminal color support

## Dependencies
```
pip install colorama
```
