# Basics — Slices, Strings, and Operators

Foundational Python exercises covering output, strings, arithmetic, and slice notation.

## Files

| File | Topic |
|---|---|
| `HelloWorld.py` | Basic print statements and arithmetic expressions |
| `Strings.py` | String literals, concatenation, f-strings, and type inspection |
| `Strings2.py` | String indexing with positive/negative indices and slice notation |
| `SliceBack.py` | Reverse slicing and step-based slice notation |
| `EscapeChar.py` | Escape characters, raw strings, and multi-line string literals |
| `Operators.py` | Arithmetic operators and operator precedence |
| `SequenceOperators.py` | String concatenation, repetition (`*`), and membership (`in`) |
| `Formatting.py` | Numeric format specifiers: width, alignment, and floating-point precision |
| `Interpolation.py` | Python 2-style `%` string interpolation (historical reference) |
| `RepFields.py` | Positional replacement fields with `str.format()` |

## Key Concepts
- String indexing and slicing (`s[start:stop:step]`)
- Negative indices for reverse access
- f-strings vs `str.format()` vs `%` interpolation
- Arithmetic and floor division operators
- Escape sequences and raw strings (`r"..."`)
