# Functions, Games, and Color Printing

Function fundamentals, mini games, and terminal color output using ANSI sequences.

## Files

| File | Topic |
|---|---|
| `functions.py` | multiply, palindrome checking, and iterative Fibonacci |
| `parameter_types.py` | `*args` variadic parameters demonstrated with a sum function |
| `factorial_function.py` | Iterative factorial printed over a range |
| `Guessing Game.py` | Player guesses a random number with higher/lower feedback |
| `hilo_test.py` | Binary search solver — tests all numbers 1–1000 and reports worst-case guess count |
| `challenge.py` | FizzBuzz game — computer prints even turns, player types odd turns |
| `color_print.py` | ANSI color and text effect sequences using `colorama` |
| `banner.py` | Centered banner printer with `**` borders at configurable screen width |
| `Menu.py` | Colored banner menu combining `banner.py` and `color_print.py` |
| `star_examples.py` | Unpacking a tuple into `*args` |

## Key Concepts
- Function definitions with type hints and docstrings
- `*args` for variadic positional parameters
- Recursive vs. iterative implementations (factorial, fibonacci)
- `try/except` inside input loops for robust user input
- ANSI escape sequences and `colorama` for cross-platform color output
- Binary search applied to a guessing game
